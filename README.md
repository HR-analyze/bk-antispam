# BK AntiSpam

Первый этап модератора комментариев Telegram-канала сети кулинарных лавок.

## Сейчас удаляется

- любая ссылка в сообщении;
- мат и распространённые завуалированные варианты;
- очевидные рекламные/спам-шаблоны;
- предложения заработка, вакансии и подработки с рекламным призывом;
- казино/ставки и похожий очевидный спам.

Обычные обращения клиентов, жалобы, вопросы про магазины, бонусы, приложение, продукты, мероприятия и сотрудников бот не трогает.

## Запуск

Переменная окружения:

```text
BOT_TOKEN=...
```

Запуск:

```bash
pip install -r requirements.txt
python bot.py
```

Для Telegram бот должен быть администратором группы обсуждений с правом удаления сообщений. Telegram разрешает боту-администратору удалять сообщения других пользователей в группе/супергруппе; для супергруппы нужен `can_delete_messages`.
